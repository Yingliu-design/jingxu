# 镜序 JINGXU

让灵感，有序成片。

一个在本机运行的 AI 分镜创作工作台，串联参考视频下载、视频与文本拆解、故事改编和分镜任务整理。

## 功能

- **视频下载**：粘贴支持平台的链接，借助 yt-dlp 和 FFmpeg 下载参考素材。
- **复刻分镜**：上传视频或输入文本，拆解画面、动作与台词；支持角色改写和故事二创。
- **分镜任务**：按视频时长整理逐镜脚本和分组任务提示词，复制结果或导出 JSON。
- **模型选择**：可配置 Gemini、OpenAI 和 DeepSeek；视频理解使用 Gemini。

项目输出脚本和提示词，不直接生成视频成片。

## 本地运行

需要 Node.js 22 或更新版本。

```bash
git clone https://github.com/Yingliu-design/jingxu.git
cd jingxu
npm ci
cp .env.example .env
```

启动：

```bash
npm start
```

打开 <http://127.0.0.1:4173>，点击右上角「API 设置」或模型服务商旁的「配置 API」，填写 API Key 和默认模型。可先检查连接，再保存；配置立即生效，无需重启。未配置模型时，仍可整理已有 Markdown 分镜。

也可以在 `.env` 中填写密钥；页面保存的配置优先于环境变量。模型名称应根据账号实际可用列表配置。

初次配置时，可查看 API 设置右侧的「配置教程」。教程随服务商切换，提供获取密钥、填写配置、检查保存的步骤，以及官方入口和常见连接问题排查。

### 可用性与试用

本项目目前适合本机测试和小范围试用。每位使用者需要自行配置 API；模型列表可读取，不代表当前模型仍有生成额度或服务空闲。「检查连接」验证的是鉴权和模型列表，首次使用还应实际生成一份短脚本。

Gemini 生成采用流式接收，传输中断和临时繁忙时会有限重试；每日额度耗尽时会直接提示。

分镜与任务统一输出全中文。已有表格先按列解析，再翻译画面提示词和配音中的英文，保留原中文、镜号、顺序、画幅及任务分组。常见术语与音效标签在本地转换；较长英文内容通过当前配置的模型分批翻译。原稿已经为中文时，整理已有分镜不需要模型。

最终输出会再次检查英文残留。分批翻译后只针对失败片段缩小范围重试；模型仍无法完成或不可用时，保留输入原稿并明确报错，不把英文原文或部分译文当成成功结果。生成失败不会用旧结果代替新输入的结果。

截至 2026-11-11，已在实际页面验证中英混合五列表格转成全中文的 60 秒、30 镜、6 个任务，并验证刷新恢复和同稿重复整理；51 项自动测试与语法检查通过。详见 [验收记录](docs/generation-acceptance.md)。这不等同于公开多用户压力测试，也不能保证第三方服务持续可用。

原台词由程序按原文位置建立清单，并在模型安排镜头后回填。模型台词编号遗漏、重复或错序时，程序按原文顺序及上下文恢复，输出会明确提示核对台词与画面的对应位置；不会将这种修复标为已确认的无损排列，也不会使用模型改写的台词替换原文。

### 视频下载配置

视频下载需要安装 yt-dlp 和 FFmpeg，确保 `yt-dlp --version`、`ffmpeg -version` 可正常运行；也可在 `.env` 的 `YTDLP_PATH`、`FFMPEG_PATH` 指定完整路径。下载不需要模型 API。

支持整段分享文字和单视频链接。小红书短链接会先还原笔记地址并保留分享参数，抖音桌面弹层与分享页链接会统一为视频地址。画质不匹配时自动重试最高可用格式。

抖音会在主下载器失败后使用本机 Chrome 或 Chromium 辅助读取公开分享页，并等待视频数据加载、有限重试。程序自动查找 macOS、Windows 和 Linux 的常见安装位置；安装在其他位置时填写 `CHROME_PATH`。

公开下载默认不读取个人登录状态。确实需要登录的视频，可在 `.env` 的 `VIDEO_COOKIE_BROWSER` 填写自己的浏览器（例如 `chrome` 或 `firefox`），仅在平台要求登录或返回无效数据时使用。配置修改后重启服务。浏览器和登录数据只使用每位使用者自己的本机环境，不随仓库分享。私密、付费、地区或账号权限限制仍由源平台决定。

备用 Cobalt 引擎是可选的，需要自行运行并通过 `COBALT_API_URL` 配置；主下载器可用时不依赖它。不同平台的下载能力仍取决于源站、网络和解析器版本，页面列出平台不代表每个视频都可下载。

2026-11-16 已实测下载小红书原始短链接、两条抖音视频、B站和 YouTube 公开视频；小红书另通过真实网页按钮验证。66 项自动测试通过，详情见 [下载验收记录](docs/download-acceptance.md)。

## 提示词与素材

使用体验和工作流受到生财教练团队相关工具的启发，本项目围绕个人创作流程做了实现与调整。

本上传版本不包含原付费平台的第三方共享提示词库。`data/prompts.json` 仅包含本项目自有的内部中文翻译规则，不在可选预设中显示。你可以使用自己的提示词，也可以不选预设直接输入文本或上传视频。

首页的猫咪短剧画面仅用于演示。使用参考视频、提示词和素材前，请确认相应授权。

## 配置与数据

- `.env`：本机密钥与配置，已加入 Git 忽略规则。
- `data/api-config.json`：页面保存的 API 配置，仅当前系统用户可读写，已加入 Git 忽略规则；不会回显密钥或写入浏览器创作记录。
- `data/prompts.json`：提示词预设列表。
- `downloads/`：本机下载结果，不提交。
- 页面创作记录保存在浏览器中，不随代码上传。

不要将自己的 `.env`、日志、浏览器创作记录或未经授权的素材提交到仓库。
