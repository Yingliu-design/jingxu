# 镜序 JINGXU

让灵感，有序成片。

一个在本机运行的 AI 分镜创作工作台，串联参考视频下载、视频与文本拆解、故事改编和分镜任务整理。

## 功能

- **视频下载**：粘贴支持平台的链接，借助 yt-dlp 和 FFmpeg 下载参考素材。
- **复刻分镜**：上传视频或输入文本，拆解画面、动作与台词；支持角色改写和故事二创。
- **分镜任务**：按视频时长整理逐镜脚本和分组任务提示词，复制结果或导出 JSON。
- **模型选择**：可配置 Gemini、OpenAI 和 DeepSeek；视频理解使用 Gemini。

项目输出脚本和提示词，不直接生成视频成片。

## 本地运行

需要 Node.js 22 或更新版本。

```bash
git clone https://github.com/Yingliu-design/jingxu.git
cd jingxu
npm ci
cp .env.example .env
```

启动：

```bash
npm start
```

打开 <http://127.0.0.1:4173>，点击右上角「API 设置」或模型服务商旁的「配置 API」，填写 API Key 和默认模型。可先检查连接，再保存；配置立即生效，无需重启。未配置模型时，仍可整理已有 Markdown 分镜。

也可以在 `.env` 中填写密钥；页面保存的配置优先于环境变量。模型名称应根据账号实际可用列表配置。

初次配置时，可查看 API 设置右侧的「配置教程」。教程随服务商切换，提供获取密钥、填写配置、检查保存的步骤，以及官方入口和常见连接问题排查。

视频下载还需要安装 yt-dlp 和 FFmpeg，并确保命令可在终端执行；也可以通过 `.env` 的 `YTDLP_PATH`、`FFMPEG_PATH` 指定路径。不同平台的下载能力取决于 yt-dlp 与平台当前状态。

## 提示词与素材

使用体验和工作流受到生财教练团队相关工具的启发，本项目围绕个人创作流程做了实现与调整。

本上传版本不包含原付费平台的第三方共享提示词库，`data/prompts.json` 默认为空数组。你可以使用自己的提示词，也可以不选预设直接输入文本或上传视频。

首页的猫咪短剧画面仅用于演示。使用参考视频、提示词和素材前，请确认相应授权。

## 配置与数据

- `.env`：本机密钥与配置，已加入 Git 忽略规则。
- `data/api-config.json`：页面保存的 API 配置，仅当前系统用户可读写，已加入 Git 忽略规则；不会回显密钥或写入浏览器创作记录。
- `data/prompts.json`：提示词预设列表。
- `downloads/`：本机下载结果，不提交。
- 页面创作记录保存在浏览器中，不随代码上传。

不要将自己的 `.env`、日志、浏览器创作记录或未经授权的素材提交到仓库。
